MIC v2 = texto · MIC-B = binario. Los dos son equivalentes por conversión sin pérdida — un nodo que recibió bytes MIC-B puede imprimirlos como texto MIC v2 y un LLM descendente los lee de forma idéntica. La fila MIC-B de 11,3× arriba es byte-equivalente (bytes binarios vs tokens JSON, normalizados a la misma base) para que la comparación de barras sea homogénea.

ProtoBuf / FlatBuffers

Cannot be embedded in text prompts. Compilación de esquema requerida. Opaco a la atención del LLM.

MessagePack / CBOR

Sensible a la versión del esquema. Orden de claves del mapa definido por implementación → sin hash estable.

MIC v2 + MIC-B + MAP

Legible por LLM Y eficiente en binario. Ordenación canónica por especificación; el hash ES la identidad.

canonical ordering
implicit IDs (no prefix)
tokenizable por LLM
texto ⇄ MIC-B ida y vuelta
reproducción estable por décadas

Por qué importa para la validación clínica: un formato de cable no determinista rompe el contrato de reproducción de auditoría. JSON/ProtoBuf/CBOR admiten varianza de serialización — el mismo IR puede producir bytes distintos. MIC v2 + MIC-B lo prohíben por especificación de canonicalización (floats Grisu3, cadenas NFC, operandos/atributos ordenados). MAP (Memory Address Protocol) añade enrutamiento por contenido para que los nodos recuperen conocimiento por hash, no por URL.

  1. Compuerta de clasificación de datos del paciente — classify.lane in ["clinical_knowledge", "phi_lane"]; las cargas de phi_lane se descartan antes del transporte.

  4. Reverificación de datos entrantes — el depurador se ejecuta de nuevo al recibir; defensa en profundidad contra nodos mal configurados.

    input  site_x25519_private:  X25519PrivateKey
    input  peer_pubkey:          X25519PublicKey
    input  peer_record:          FederatedRecord
    output emitted, ingested:    FederatedRecord, LocalKnowledge

    // EGRESS — this site → peers
    node classify  = @native federation_classify(finding)
    invariant classify.lane in ["clinical_knowledge", "phi_lane"]
    node scrubbed  = @native phi_strip(classify.payload)
    invariant scrubbed.has_phi == false
    node signed    = @native ed25519_sign(scrubbed.payload, site_key, site_epoch)
    invariant signed.canonical_preimage_schema == "TAG_v1_NUL_separated"

    // 6.5: encrypt the signed envelope before it touches the wire
    node sealed    = @native x25519_seal(
        signed.payload, recipient_public_key: peer_pubkey,
        cipher: "chacha20-poly1305",  kdf: "hkdf-sha256",
        per_record_nonce: true,
    )
    invariant sealed.payload_encrypted == true
    invariant sealed.has_aead_tag == true

    node emitted_record = @flow mind_mem_publish(sealed.payload, ...)

    // INGRESS — peers → this site
    node opened    = @native x25519_open(peer_record, site_x25519_private, ...)
    invariant opened.decryption_succeeded == true
    invariant opened.aead_tag_verified == true
    node verified  = @native ed25519_verify(opened.payload)
    invariant verified.signature_valid == true
    invariant verified.key_epoch_revoked == false
    node inbound_scrub = @native phi_strip(verified.payload)
    invariant inbound_scrub.has_phi == false
    node quorum    = @native severity_quorum(verified.payload, peer_quorum, 3, 5)
    node local_record = @native mind_mem_ingest(inbound_scrub.payload, ...)
}
